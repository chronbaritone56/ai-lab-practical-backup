# AI Lab Practical Backup

A beginner-friendly backup pack for practising the AI lab topics from the provided journal.

## Contents
- `AI_Lab_Practicals.ipynb` — all 10 practicals in one Google Colab/Jupyter notebook, with explanations, code, expected output notes, and viva questions.
- `practicals/` — each practical as a separate Python file.
- `PRACTICAL_REVISION.md` — quick revision and viva prompts.

## Run in Google Colab
1. Open Google Colab: https://colab.research.google.com/
2. Choose **File → Upload notebook** and upload `AI_Lab_Practicals.ipynb`.
3. Run one cell at a time using the play button or Shift+Enter.
4. If a library import fails, run `!pip install scikit-learn` in a new cell.

## Put this on GitHub
1. Sign in to GitHub and choose **New repository**.
2. Name it `ai-lab-practical-backup`.
3. Choose Public or Private according to your preference; add a README if you want, then create it.
4. In the new repository, choose **Add file → Upload files**.
5. Upload `AI_Lab_Practicals.ipynb`, `PRACTICAL_REVISION.md`, and the `practicals` folder (or upload the ZIP's extracted contents).
6. Commit the files.

## Open the notebook from GitHub in Colab
Once uploaded, open this format in your browser, replacing `YOUR-USERNAME` with your GitHub username:
`https://colab.research.google.com/github/YOUR-USERNAME/ai-lab-practical-backup/blob/main/AI_Lab_Practicals.ipynb`

## Important for the practical
Use this as a study backup, not as something to blindly copy. Practise typing each program, explain what each function does, and change the inputs to see what happens. Your teacher may use a different question or expect a version that matches your lab journal exactly, so compare these examples with your prescribed journal.
